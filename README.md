# tv-remote-keys — «Кнопки пульта»

Крошечное приложение для Android TV / Google TV, которое переназначает фирменные кнопки пульта
(Netflix, Prime Video, Xiaomi TV+ и любые другие) на запуск нужных вам приложений. Без root,
без рекламы, без доступа в интернет; APK весит около 20 КБ.

*A tiny Android TV app that remaps the remote's branded shortcut buttons (Netflix, Prime Video,
Xiaomi TV+, or any other key) to launch apps of your choice. No root, no ads, no network access.*

## Зачем

На Xiaomi TV Box S (2nd Gen) кнопки Netflix и Prime Video жёстко привязаны к этим приложениям
системным обработчиком Xiaomi, и без root его не перенастроить. Это приложение перехватывает
нажатие раньше него и открывает то, что выбрали вы.

## Как это работает

- Служба специальных возможностей (`AccessibilityService` с `flagRequestFilterKeyEvents`) получает
  нажатия клавиш до системного обработчика.
- Если для кода клавиши назначено приложение, служба запускает его и «съедает» нажатие.
  Остальные клавиши проходят как обычно.
- Содержимое экрана служба не читает (`canRetrieveWindowContent="false"`), разрешения на
  интернет у приложения нет.

## Настройка на телевизоре

Откройте «Кнопки пульта» в списке приложений:

- выберите кнопку и приложение из установленных;
- «Добавить другую кнопку» — нажмите на пульте любую кнопку, затем выберите приложение.
  Стрелки, OK, «Назад», «Домой» и громкость назначить нельзя.

Назначения по умолчанию задаются в [`assets/keys.txt`](assets/keys.txt) и применяются при первом
запуске. В репозитории там пример; поменяйте пакеты на свои перед сборкой или уже в приложении.

## Коды кнопок

Проверено на Xiaomi TV Box S 2nd Gen (MiTV-AFKR0, Google TV / Android 11, сборка
`RTT0.211222.001.683`):

| Кнопка | Код клавиши Android |
|---|---|
| Netflix | 193 (`BUTTON_6`) |
| Prime Video | 194 (`BUTTON_7`) |
| Xiaomi TV+ | 192 (`BUTTON_5`) |

На других устройствах и прошивках коды могут отличаться — используйте «Добавить другую кнопку»,
приложение само покажет код.

## Сборка и установка

Нужны JDK 17, Android SDK (`platforms;android-34`, `build-tools;34.0.0`) и `adb`. На macOS:

```bash
brew install openjdk@17 android-platform-tools
brew install --cask android-commandlinetools
sdkmanager --sdk_root=/opt/homebrew/share/android-commandlinetools "platforms;android-34" "build-tools;34.0.0"
```

На приставке включите отладку: Настройки → Система → Об устройстве → 7 раз OK на «Сборка»,
затем «Для разработчиков» → «Отладка по USB». После этого:

```bash
./build-and-install.sh <ip приставки>   # собрать, установить и включить службу
./build-and-install.sh --build          # только собрать build/tvkeys.apk
```

Скрипт собирает APK без Gradle (aapt2 → javac → d8 → apksigner), подписывает его локальным
ключом, который создаётся при первой сборке, ставит по ADB и включает службу через
`settings put secure enabled_accessibility_services`. Если на приставке уже включены другие
службы специальных возможностей, скрипт их перезапишет — включите их заново в настройках.

Другие пути к JDK и SDK задаются переменными `JAVA_HOME` и `ANDROID_HOME`.

## Ограничения

- Перехватываются только настоящие нажатия пульта. Нажатия, отправленные через
  `adb shell input keyevent`, идут мимо службы — так устроен Android.
- Если кнопки перестали работать (например, после перезагрузки или обновления приложения),
  проверьте, что служба «Кнопки пульта» включена в Настройки → Система → Специальные возможности.
- Проверено на одном устройстве, указанном выше.

## Удаление

```bash
adb uninstall local.tvhome.keys
```

Кнопки вернутся к прежнему поведению.
